## 4. What it changes on your laptop

SoundModes changes only what's needed to work:

- It rewrites Equalizer APO's `config.txt` each time you switch modes. Your original file is saved once as
  `config.txt.soundmodes-backup`.
- It stores your settings in `%APPDATA%\SoundModes`.
- If you turn on **Start with Windows**, it adds a startup entry for your user account.
- If you click **Grant permission**, it gives standard Windows users write access to Equalizer APO's config folder.

To undo everything, follow **Uninstall** in the [README](../README.md).
